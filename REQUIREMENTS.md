# 要件書：Nostr Custom Emoji ハイパーつくるくん

バージョン：1.0  
対象：AIエージェントによる実装

---

## 1. プロジェクト概要

Nostrのカスタム絵文字をグリッドに配置し、カスタム絵文字アートを作成・投稿するWebアプリケーション。

### 1.1 技術スタック（固定）

| 項目                 | 指定                  |
| -------------------- | --------------------- |
| フレームワーク       | SvelteKit             |
| リレー通信           | rx-nostr              |
| 認証・署名           | @konemono/nostr-login |
| 言語                 | TypeScript            |
| 対象プラットフォーム | Web（PC / スマホ）    |

---

## 2. 型定義

実装全体で以下の型を共有する。変更不可。

```typescript
// カスタム絵文字タグ
// 4要素目はノラ絵文字（10030直接登録）の場合は省略
type EmojiTag = ["emoji", string, string, string?];
// ["emoji", resolvedShortcode, url, "30030:pubhex:identifier"]

// グリッドのセル。null = 空セル
type Cell = EmojiTag | null;

// グリッド全体
type Grid = Cell[][];

// パレットの絵文字エントリ
interface PaletteEmoji {
  shortcode: string; // 衝突解消済みショートコード
  url: string;
  ref?: string; // "30030:pubhex:identifier"（ノラ絵文字は省略）
  originalShortcode: string; // 衝突前の元ショートコード
}

// null絵文字の設定
interface NullEmojiConfig {
  type: "custom" | "fullwidth_space";
  emoji?: PaletteEmoji; // type === "custom" の場合
}
```

## 3. 機能要件

### 3.1 認証（AUTH）

| ID      | 要件                                                                      |
| ------- | ------------------------------------------------------------------------- |
| AUTH-01 | @konemono/nostr-login を使用してログインする                              |
| AUTH-02 | ログイン状態をアプリ全体で管理する                                        |
| AUTH-03 | ログイン後、kind 10030 の取得フローを自動で開始する                       |
| AUTH-04 | kind 10030 が存在しない場合、エラーメッセージを表示してパレットを空にする |

### 3.2 パレット（PALETTE）

| ID     | 要件                                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------------------- |
| PAL-01 | ログイン済みユーザーのpubkeyを使い、以下のフローで絵文字を取得する                                                     |
| PAL-02 | 取得フロー①：ハードコード済み既知リレーから kind 10002 を取得する                                                      |
| PAL-03 | 取得フロー②：10002 の読みリレーから kind 10030 を取得する                                                              |
| PAL-04 | 取得フロー③：10030 の `a` タグが指す kind 30030 を読みリレーから取得する（メイン）                                     |
| PAL-05 | 取得フロー④：PAL-04 で取得できない場合、`a` タグのリレーヒントから取得する（フォールバック）                           |
| PAL-06 | 10030 に直接記載された `emoji` タグ（ノラ絵文字）も列挙する                                                            |
| PAL-07 | 同名ショートコードが複数存在する場合、`pubkey+dtag` でソートして先勝ちとし、後続には連番suffix（`_2`、`_3`）を付与する |
| PAL-08 | 衝突解消済みパレットリストを localStorage に保存する                                                                   |
| PAL-09 | 起動時は localStorage からパレットを復元する                                                                           |
| PAL-10 | リレーからデータ受信時は localStorage のパレットリストを上書きする                                                     |
| PAL-11 | パレットはスクロールスパイ型タブUIを使用する（スクロールに合わせて現在表示中のセクションがハイライトされる）           |
| PAL-12 | パレットのセクション例：「みんなの30030絵文字セット」「自分の30030絵文字セット」「10030に直入れしている絵文字」       |

### 3.3 絵文字選択（SELECT）

| ID     | 要件                                             |
| ------ | ------------------------------------------------ |
| SEL-01 | パレットで絵文字をクリックすると選択状態になる   |
| SEL-02 | 選択中の絵文字を再クリックすると選択が解除される |
| SEL-03 | 「選択解除」ボタンで選択を解除できる             |
| SEL-04 | 選択中の絵文字はプレビューエリアに表示される     |

### 3.4 グリッド操作（GRID）

| ID      | 要件                                                                   |
| ------- | ---------------------------------------------------------------------- |
| GRID-01 | 初期サイズは 8×8                                                       |
| GRID-02 | 最大サイズは 64×64                                                     |
| GRID-03 | 以下のタップ挙動に従う                                                 |
| GRID-04 | 絵文字選択中 + 空セル → 絵文字を配置する                               |
| GRID-05 | 絵文字選択中 + 配置済み（別の絵文字） → 上書きする                     |
| GRID-06 | 絵文字選択中 + 配置済み（同じ絵文字） → コンテキストメニューを表示する |
| GRID-07 | 選択解除中 + 配置済みセル → コンテキストメニューを表示する             |
| GRID-08 | 選択解除中 + 空セル → 何もしない                                       |

### 3.5 コンテキストメニュー（CTX）

| ID     | 要件                                                       |
| ------ | ---------------------------------------------------------- |
| CTX-01 | 「削除」：対象セルを null に戻す                           |
| CTX-02 | 「パレットにコピー」：対象絵文字をパレットの選択状態にする |

### 3.6 グリッドサイズ変更（RESIZE）

| ID     | 要件                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| RSZ-01 | グリッドの上端・下端・左端・右端に `+` ボタンを配置する                        |
| RSZ-02 | 下端 `+`：末尾に1行追加                                                        |
| RSZ-03 | 右端 `+`：末尾に1列追加                                                        |
| RSZ-04 | 上端 `+`：先頭に1行挿入                                                        |
| RSZ-05 | 左端 `+`：先頭に1列挿入                                                        |
| RSZ-06 | 各行・列の削除ボタンを配置する                                                   |
| RSZ-06-1 | PC：ホバー時に削除ボタン（`−`）を表示                                           |
| RSZ-06-2 | スマホ：グリッド端に常時表示、タップで確認ダイアログ→削除                       |
| RSZ-07 | 配置済み絵文字が存在する行・列を削除しようとした場合、確認ダイアログを表示する |

### 3.7 スクロール（SCROLL）

| ID     | 要件                                                                          |
| ------ | ----------------------------------------------------------------------------- |
| SCR-01 | WASDキーでグリッドを2セル分スクロールする（PC・スマホ共通）                   |
| SCR-02 | ブラウザ標準スクロール（マウスホイール・タッチ）も有効にする                  |
| SCR-03 | スマホ向けに画面上に ⌨ ボタンを配置し、ソフトキーボードを呼び出せるようにする |

### 3.8 null絵文字（NULL）

| ID      | 要件                                                                          |
| ------- | ----------------------------------------------------------------------------- |
| NULL-01 | アプリ固有の透明・正方形カスタム絵文字をデフォルトnull絵文字として使用する    |
| NULL-02 | null絵文字はパレットとは独立して管理する（ユーザーの10030未登録でも使用可能） |
| NULL-03 | ユーザーはパレットから任意の絵文字をnull絵文字として変更できる                |
| NULL-04 | 全角スペース（`\u3000`）もnull絵文字として選択可能だが、非推奨として明示する  |
| NULL-05 | null絵文字の設定を localStorage に保存する                                    |

### 3.9 出力（OUTPUT）

| ID     | 要件                                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| OUT-01 | 出力前に、nullのみで構成される上端・下端・左端・右端の行・列をトリムする                                                    |
| OUT-02 | トリムはグリッドの表示・編集状態に影響しない（出力専用処理）                                                                |
| OUT-03 | トリム後のサイズ（例：`5列×3行`）をコピー・投稿エリアに表示する                                                             |
| OUT-04 | 各セルを `:shortcode:` 形式で出力する                                                                                       |
| OUT-05 | 空セルはnull絵文字の `:shortcode:` 形式で出力する                                                                           |
| OUT-06 | null絵文字が全角スペースの場合、空セルを `\u3000` で出力する                                                                |
| OUT-07 | 各行はセルをそのまま横に並べ、行間を `\n` で区切る                                                                          |
| OUT-08 | 「contentをコピー」ボタンで生成テキストをクリップボードにコピーする                                                         |
| OUT-09 | 「kind 1で投稿」ボタンで @konemono/nostr-login を使って署名し、kind 1 イベントを 10002 の書きリレーに投稿する               |
| OUT-10 | kind 1 の `tags` に、使用した絵文字 + null絵文字を重複なく列挙する                                                          |
| OUT-11 | tags フォーマット（30030参照あり）：`["emoji", "shortcode", "url", "30030:pubhex:identifier"]`                              |
| OUT-12 | tags フォーマット（ノラ絵文字）：`["emoji", "shortcode", "url"]`                                                            |
| OUT-13 | shortcode に使用できる文字は英数字・ハイフン・アンダースコアのみ（NIP-30準拠）。衝突解消suffix（`_2` 等）もこの制約を満たす |

### 3.10 永続化（STORE）

| ID     | 要件                                                       |
| ------ | ---------------------------------------------------------- |
| STR-01 | グリッドの内容（`Cell[][]`）を localStorage に自動保存する |
| STR-02 | 衝突解消済みパレットリストを localStorage に保存する       |
| STR-03 | null絵文字の設定を localStorage に保存する                 |
| STR-04 | 起動時に localStorage から全データを復元する               |
| STR-05 | localStorage からの復元によりオフライン使用を可能にする    |

---

## 4. 非機能要件

| ID    | 要件                                                                              |
| ----- | --------------------------------------------------------------------------------- |
| NF-01 | PCレイアウト（横並び：パレット + グリッド）とスマホレイアウト（縦積み）を実装する |
| NF-02 | スマホレイアウトの切り替えブレークポイントは 768px 以下とする                     |
| NF-03 | グリッドが画面に収まらない場合はスクロール可能にする                              |
| NF-04 | 初回ロード時（localStorage なし・未ログイン）でもグリッドは操作可能にする         |

---

## 5. スコープ外（v1）

以下はv1実装対象外とする。

- 絵文字セット管理ページ（30030の一覧・10030への追加・除外）
- 10030未所持ユーザーの初期セットアップフロー
- ノラ絵文字の手動入力UI
