# Nostr Custom Emoji ハイパーつくるくん 設計書

## 概要

Nostr のカスタム絵文字を1セル1絵文字のグリッドに配置し、
カスタム絵文字アートを作成・投稿するツール。
出力は Nostr kind 1 投稿として使用できるテキスト形式。

---

## 技術スタック

- **フレームワーク**：SvelteKit
- **Nostr ライブラリ（リレー通信）**：rx-nostr
- **Nostr ライブラリ（ログイン・署名）**：@konemono/nostr-login
- **対象プラットフォーム**：Web（PC / スマホ）

## グリッドの仕様

- 1セル = カスタム絵文字1個（正方形想定）
- 空セルは null 絵文字として出力する（後述）
- グリッドは行列構造で管理する

```typescript
type Cell = { shortcode: string; url: string } | null;
type Grid = Cell[][];
```

---

## null 絵文字の仕様

カスタム絵文字はクライアント間で表示幅が統一されるため、
AA的な幅の一貫性を保つために空セルもカスタム絵文字として出力する。

### デフォルト null 絵文字

- アプリ固有の正方形・透明絵文字を用意する
- この絵文字はアプリ運営側が kind `30030` イベントとしてホストする
- ユーザーはこのアプリ用 30030 を自分のカスタム絵文字リストに登録しておくことで、
  コピペ先クライアントでも補完が効く

### null 絵文字の変更

- ユーザーはパレットから任意の絵文字を null 絵文字として選択できる
- 選択した絵文字が空セルの出力に使われる（背景として機能する）
- 全角スペース（`\u3000`）もオプションとして選択可能だが、
  クライアント依存で幅がズレる可能性があるため非推奨として明示する

---

## 出力形式

グリッドを以下のルールで kind 1 の content テキストに変換する。

- 各セル：絵文字は `:shortcode:` 形式
- 空セル：設定中の null 絵文字の `:shortcode:` 形式
- 各行：セルをそのまま横に並べる
- 行間：改行（`\n`）で区切る

### 例

null 絵文字: `:blank:` / グリッド：

```
[null] [cat  ] [null]
[star ] [null ] [party]
```

出力 content：

```
:blank::cat::blank:
:star::blank::party:
```

kind 1 イベントの `tags` には、使用した絵文字 + null 絵文字を重複なく列挙する：
最新のカスタム絵文字の仕様をかくにんすること。

```json
["emoji", "blank", "https://example.com/blank.png",30030:<pubhex>:<identifier>],
["emoji", "cat", "https://example.com/cat.png",30030:<pubhex>:<identifier>],
["emoji", "star", "https://example.com/star.png",30030:<pubhex>:<identifier>],
["emoji", "party", "https://example.com/party.png",30030:<pubhex>:<identifier>]
```

## 機能一覧

### 1. ログイン

- `@konemono/nostr-login` を使用する
- ログイン後に pubkey を取得し、kind 10030 の取得に使用する

### 2. 絵文字選択

- パレットから絵文字をクリックして選択状態にする
- 選択中の絵文字はプレビューエリアに表示される

### 3. セルへの配置

- 選択状態の絵文字がある場合、グリッドのセルをクリックするとその絵文字が配置される

### 4. 配置済み絵文字の操作（ドラッグ&ドロップ）

- セル上の絵文字を長押しして掴む
- **ゴミ箱にドロップ**：絵文字を削除する（null に戻す）
- **別のセルにドロップ**：その絵文字をドロップ先セルに移動する
- ゴミ箱はドラッグ開始時のみ表示する（通常時は非表示）

### 5. 連続書き込みモード

- 専用トグルでモードを切り替える
- モード有効中にグリッド上をドラッグ（なぞる）すると、通過したセル全てに選択中の絵文字が書き込まれる

### 6. グリッドサイズ変更

- グリッドの行末尾・列末尾に `+` ボタンを配置する
- `+` ボタンをクリックすると、その行または列が1つ追加される
- TODO: 行・列の削除操作と、削除時に配置済み絵文字が存在する場合の挙動

### 7. パレット絵文字の取得

rx-nostr を使用して以下のフローで絵文字リストを取得する。

1. ログイン済み pubkey で kind `10030` イベントを取得する
2. `10030` の `a` タグが指す kind `30030` イベント群を取得する
3. `30030` イベントの `emoji` タグ（`["emoji", shortcode, url]`）を列挙し、パレットに表示する
4. TODO: フォールバック対応（10030未設定のユーザー向けのデモセットまたは手動URL入力）

### 8. 出力

- **contentをコピーボタン**：生成した content テキストをクリップボードにコピーする
- **kind 1で投稿ボタン**：`@konemono/nostr-login` で署名し、kind 1 イベントをリレーに投稿する
